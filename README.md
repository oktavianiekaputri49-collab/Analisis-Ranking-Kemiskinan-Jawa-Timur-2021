# Analisis-Ranking-Kemiskinan-Jawa-Timur-2021
Project ini membahas analisis ranking tingkat kemiskinan kabupaten/kota di Jawa Timur tahun 2021 menggunakan data dari Badan Pusat Statistik (BPS). Analisis dilakukan untuk mengidentifikasi daerah dengan tingkat kemiskinan tertinggi dan terendah serta memahami distribusi kemiskinan antar wilayah di Jawa Timur.
